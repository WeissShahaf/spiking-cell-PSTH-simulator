Window length: fixed windows vs a window set by the response

Same cell, each test re-run with the response window ending at 0.25, 0.5, 1, 2 (the default) and 3 s, and once with a derived window that ends where this cell's response ends: latency + 2 × the latency jitter SD (covers about 98% of trials) + response length (3 × duration for the peak shape, so its tail is inside), rounded up to 0.05 s and kept between 0.25 and 3 s. Shape axis: Cramér–von Mises vs uniform and ZETA use the same end for their timing window (the two-sample shape test keeps its fixed windows). Baseline stays −2 to −0.25 s.

How often does each test call a non-responding cell significant?

This simulates many cells with the cell settings but no response (the response is switched off), runs each test, and counts how many are called significant. A fair test at α = 0.05 should land near 5%. The toggles add common problems that can fool a test.
